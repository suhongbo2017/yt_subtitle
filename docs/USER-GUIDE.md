# 使用手册

> 面向**使用者**。只想把东西用起来看这份就够了。
> 想看架构/踩坑/如何改代码 → [`HANDOVER.md`](HANDOVER.md)

---

## 0. 一分钟了解它能干什么

| 你想做的事 | 用哪个功能 | 需要额外准备 |
|---|---|---|
| 看 YouTube 视频要中文字幕 | **在线字幕**（自动） | 无 |
| 视频没有字幕（或字幕不全） | **点播字幕生成** | 启动一次 ASR 服务 |
| 就想立刻看，不想等生成 | **实时识别** | 同上 |
| 网页/软件界面上的外文看不懂 | **截图翻译** | 启动视觉服务 |
| 扫描版 PDF、图片文档要中文 | **文档翻译** | 启动视觉服务 |

四个功能**互相独立**：不用语音识别也照样能截图翻译，反过来也一样。

## 1. 一次性安装

### 1.1 装扩展

1. 打开 `chrome://extensions`
2. 右上角打开「**开发者模式**」
3. 点「**加载已解压的扩展程序**」
4. 选择目录：`D:\PI\subtitle\.output\chrome-mv3`

装好后浏览器工具栏出现绿色「译」图标。

> 如果之前装过旧版本：点扩展卡片上的**刷新按钮**，然后**刷新所有已打开的 YouTube 页面**
> （扩展更新后旧页面里没有新代码）。

### 1.2 启动本地服务

服务负责两件事，**用到哪个开哪个**：

| 服务 | 端口 | 管什么 | 怎么启动 |
|---|---|---|---|
| ASR 服务 | 8770 | 语音识别（无字幕视频） | 双击 `install-native-host.cmd`（一次性）后，在弹窗里开关 |
| 视觉服务 | 8765 | 截图翻译 / 文档翻译 | 双击 `start-ui.cmd` |

- **只想看字幕** → 什么都不用启动，扩展直接用 YouTube 自带字幕
- **想用语音识别** → 先 `install-native-host.cmd`（一次性，装完弹窗里就能启停服务）
- **想用截图/文档翻译** → 双击 `start-ui.cmd`，会弹出一个黑色命令行窗口，**别关它**

### 1.3 怎么知道服务好没好

点扩展图标，看顶部两个徽章：

```
ASR ✓    视觉 ✓    运行中
（蓝）    （紫）     （绿）
```

- `ASR` 亮蓝色 = 语音识别服务在线
- `视觉` 亮紫色 = 截图/文档翻译服务在线
- 灰色带 `✕` = 没启动（把鼠标悬上去会告诉你怎么启动）

## 2. 在线字幕（基本不用管）

打开任意 YouTube 视频，字幕自动出现在画面下方：中文在上、原文在下。

需要知道的两件事：

1. **必须开着 CC**。扩展会自己点一次，但如果你手动关掉了就不会有字幕。
2. **不是所有视频都有字幕**。YouTube 的自动字幕对纯音乐、无解说视频不生成 —— 这种情况用第 3 节。

### 弹窗里的开关

| 开关 | 作用 |
|---|---|
| 启用翻译 | 总开关，关掉完全不工作 |
| 显示原文 | 关掉只显示中文 |
| 隐藏原生字幕 | 关掉会和 YouTube 自带字幕重叠（默认开） |
| 语音识别 | 见第 3 节 |

### 换翻译引擎

点弹窗里的「Google 免费」/「LLM」：

- **Google 免费**（默认）：零配置，直译，够看
- **LLM**：需要先填 API 端点 + Key（设置页里），中文更自然、能利用上下文

切换后**立即生效**，同一句已翻译过的不再重复请求（本地有缓存）。

## 3. 没有字幕的视频：生成字幕

### 3.1 首次使用（会慢一点）

1. 打开视频页 → 点扩展图标
2. 打开「**语音识别**」开关
3. 弹窗关闭，页面上没有立刻出现字幕 —— **这是正常的**，正在后台下载音频
4. 约 1–3 分钟后（1 小时视频大约 2-3 分钟），字幕**整条出现**，可以随意拖动进度条

弹窗里会显示进度：

```
正在生成字幕… 45%
```

### 3.2 第二次看同一个视频（秒开）

字幕已经缓存在本地，打开就是**瞬时可用**、可任意 seek，不再重新识别。

### 3.3 实时识别（不想等）

如果只是想马上看，点「**改用实时识别**」：

- 约 5 秒后开始出字幕，之后每 3 秒更新一句
- 缺点：切片边界可能丢半个词，且每次都要重新跑

### 3.4 想要更准

默认用 `base` 模型（快）。中文或口音重在命令行里换 small：

```cmd
start-asr.cmd --model small
```

### 3.5 如果提示"没有识别到语音"

说明这段音频里要么没人声（纯音乐），要么音量太低。这是模型能力边界，不是故障。可以：

- 换 small 模型再试一次（弹窗开关关掉再打开，或删掉缓存重跑）
- 演唱类视频（歌词被唱出来）识别质量会明显下降

## 4. 截图翻译

适合：网页上的外文、软件界面、游戏画面、图表标注。

1. 打开要翻译的页面
2. 点扩展图标 → 点蓝色「**📝 截图翻译（当前页面）**」
3. 弹窗自动关闭，页面上出现**绿色选框**
4. **拖拽**框住要翻译的区域（拖动时会显示宽高）
   - 想全页翻译：点顶部工具条的「**整页**」
   - 想放弃：按 `Esc` 或点「取消」
5. 等约 10 秒，自动打开新标签页显示结果

### 结果页怎么用

| 操作 | 说明 |
|---|---|
| 「只看译文」 | 隐藏原文对照 |
| 「字号」滑杆 | 译文太大/太小 |
| 每块的「复制」 | 只复制那句 |
| `Ctrl+C` | 未选中文字时，复制**全部**原文+译文 |
| 「打印」 | 直接输出 PDF |

译文会**叠在原文位置上**，所以看起来像"原件的中文版"。

> 隐私提醒：截图内容会发送给你配置的云端视觉模型。

## 5. 文档翻译（扫描版 PDF / 图片）

1. 双击 `start-ui.cmd`（会打开浏览器界面 `http://127.0.0.1:8765/`）
2. 把 PDF 或图片**拖进左侧区域**（也可以从 `samples/` 目录里勾选）
3. 右侧确认设置：
   - 模型（首次用默认即可；下拉里可切换）
   - 目标语言
   - 页码范围（留空=全部）
   - 「生成覆盖式 HTML」建议勾上
4. 点「**开始翻译**」
5. 底部有实时日志和进度；完成后右侧「结果」区出现三个链接：

| 链接 | 内容 |
|---|---|
| **HTML 预览** | 原页做底图、译文按原位置贴回，最接近原件观感；可调底图浓度、字号、可打印 |
| **双语 PDF** | 原页 + 译文页对照，表格会渲染成真表格 |
| **译文 MD** | 纯文本，方便复制到别处 |

### 小技巧

- 首次跑同一份文档后，**改排版/重跑不花钱**（逐页结果有缓存）
- 表格多的文档优先看 HTML（PDF 里宽表格会挤）
- 手写体识别按页看效果，个别页不准可以只重跑那几页（`--pages`）

## 6. 弹窗「运行状态」怎么读

弹窗底部这块告诉你**当前在跑什么**：

```
运行状态                              已注入
┌───────────────────────────────────────────┐
│ [在线字幕]   已就绪（YouTube 字幕轨）      │
│ 引擎         Google 免费 / qwen3.8-flash  │
│ 字幕         128 条 · 已译 96             │
│ 当前显示     「今年的价格简直疯了」         │
│ 错误         —                            │
└───────────────────────────────────────────┘
```

- 方括号里是**当前功能**：`在线字幕` / `点播字幕` / `实时识别` / `等待字幕`
- `字幕 N 条 · 已译 M`：条数是拿到的字幕总数，已译是翻译完的
  - **条数明显少于视频实际句数** → 这个视频的字幕轨本身有断档（音乐/静音段），走语音识别
  - **条数够但已译远小于条数** → 翻译被限流，换 LLM 引擎
- `错误` 行不为空时会一直显示（不会几秒后消失），照上面写的原因处理

## 7. 常见问题

| 现象 | 原因 / 怎么处理 |
|---|---|
| 完全没有字幕 | ① 视频没有字幕轨（用语音识别）② CC 被关了（点播放器右下角 CC）③ 扩展刚更新过 → 刷新页面 |
| 字幕只有中文没有原文 | 弹窗里「显示原文」被关了 |
| 字幕和 YouTube 原生字幕重叠 | 弹窗里打开「隐藏原生字幕」 |
| 字幕中间有空白段 | 说明这段是音乐/静音，YouTube 字幕轨本身没内容；或者用了实时识别模式 |
| 换视频后字幕不更新 | 刷新页面；仍不行就把弹窗里的开关关掉再打开 |
| 点「语音识别」没反应 | 看顶部 `ASR` 徽章是否灰的 → 服务没启动，双击 `install-native-host.cmd` 装一次，之后弹窗开关即可 |
| 生成字幕一直不动 | 看命令行窗口/`.cache/asrsvc.log`；常见是网络问题导致下载失败，稍后重试 |
| 截图翻译点完没反应 | 看屏幕右下角**系统通知**（错误都走那里，因为弹窗已关闭）；通常是视觉服务没启动 |
| 截图翻译位置错乱 | 框太小（<12px 会被忽略）或者拖太快；重新框一次 |
| 文档翻译某页空白 | 该页确实没文字，或识别失败；单独重跑那一页 |
| Google 翻译报错 | 免费接口偶尔限流，切 LLM 引擎即可 |

更多排查（看日志、端口、服务状态）见 [`HANDOVER.md` 第 11 节](HANDOVER.md#11-排障手册)。

## 8. 数据与隐私

| 内容 | 存在哪 |
|---|---|
| 翻译缓存（句子级） | 浏览器扩展本地存储 |
| 生成的视频字幕 | `D:\PI\subtitle\.cache\asr\<视频ID>.json` |
| 下载的视频音频 | `.cache\audio\`（可安全删除，会重新下载） |
| 文档翻译结果 | `out\` 目录 |
| 各类日志 | `.cache\asrsvc.log`、`.cache\native-host.log` |

**会离开本机的数据**：

- 视频字幕文本 → 发给你选的翻译引擎（Google 或你配的 LLM）
- 截图 / 文档图片 → 发给你配的视觉模型

**不会离开本机的**：视频音频文件本身（只用于本地 whisper 识别）、YouTube 登录 cookie
（只在本机传给 yt-dlp 下载音频）。

## 9. 清理与卸载

```cmd
stop-asr.cmd                   :: 停掉 ASR 服务
uninstall-native-host.cmd      :: 移除扩展启停服务的能力
```

彻底删除：`chrome://extensions` 里移除扩展 → 删除整个 `D:\PI\subtitle` 目录
（缓存都在里面，一起清掉了）。
